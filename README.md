# Skills

## Фриланс — `freelance/`

| Скилл | Что делает |
| --- | --- |
| `1-screen` | Концепция первого экрана по ТЗ с публикацией на витрине |
| `2-response` | Отклик на заказ с биржи с подбором кейсов |
| `3-audit` | Клиентский аудит сайта с отчётом в Google Таблице |
| `4-landing` | Продающий лендинг в Figma |

## Продуктовый дизайн — `product/`

Этапы идут по порядку: от поиска конкурентов до анализа опроса.

| Скилл | Что делает |
| --- | --- |
| `1-rivals` | Поиск и структурирование конкурентов |
| `2-guide` | Гайд для UX-интервью |
| `3-interview` | Анализ интервью и юзабилити-тестов |
| `4-jtbd` | Артефакты Jobs To Be Done |
| `5-survey` | Количественная анкета |
| `6-stats` | Анализ результатов опроса |

## Подключение

Скиллы подключаются симлинками, имя ссылки совпадает с именем скилла:

```bash
ln -s ~/Work/Skills/freelance/1-screen ~/.claude/skills/1-screen
```
