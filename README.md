# Skills

## Фриланс — `freelance/`

| Скилл | Что делает |
| --- | --- |
| `1-screen` | Концепция первого экрана по ТЗ с публикацией на витрине |
| `2-response` | Отклик на заказ с биржи с подбором кейсов |
| `3-figma` | Технический стандарт макетов в Figma: переменные, стили, компоненты, SVG, профили лендинга и Tilda |
| `4-marketing` | Продающая структура, доверие, тексты и проверка конверсии любой страницы на любой платформе |
| `5-tilda` | Перенос макета из Figma в Tilda: Zero Block с адаптивом, стили, картинки, SEO |
| `6-audit` | Клиентский аудит сайта с отчётом в Google Таблице |

Страница от заказа до сайта: `1-screen` и `2-response` (отклик) → `4-marketing` (что и в каком порядке говорить) + `3-figma` (как нарисовать) → `5-tilda` (перенос) → `6-audit` (аудит готового сайта). `4-marketing` работает и отдельно: с макетом, страницей Tilda или сайтом по ссылке.

## Продуктовый дизайн — `product/`

Этапы идут по порядку: от поиска конкурентов до анализа опроса.

| Скилл | Что делает |
| --- | --- |
| `1-rivals` | Поиск и структурирование конкурентов |
| `2-guide` | Гайд для UX-интервью |
| `3-interview` | Анализ интервью и юзабилити-тестов |
| `4-jtbd` | Артефакты Jobs To Be Done |
| `5-survey` | Количественная анкета |
| `6-stats` | Анализ результатов опроса |

## Подключение

Скиллы подключаются симлинками, имя ссылки совпадает с именем скилла:

```bash
ln -s ~/Work/Skills/freelance/1-screen ~/.claude/skills/1-screen
```
