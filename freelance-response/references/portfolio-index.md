## Как выбирать между кейсами

- Для образовательного проекта с проблемой навигации сначала проверяй `talantum-exam-courses`.
- Для детского центра, школы, студии, кружков, команды и эмоциональной подачи сначала проверяй `navadkovskom-creative-center`.
- Для B2B, производства, оборудования, сложного каталога или технического контента сначала проверяй `railway-service-corporate`.
- Для интернет-магазина без отраслевого совпадения железнодорожный кейс может быть полезнее образовательного, если главная задача — каталог, фильтры и разные объемы характеристик.
- Для редизайна не называй кейс центра творчества редизайном: он создавался с нуля.
- Для Tilda-лендинга с анимациями, SEO-настройкой или продажей билетов проверяй `hockey-event-tilda`.
- Для недвижимости, каталога квартир, калькулятора или кастомного кода внутри Tilda проверяй `residential-complex-tilda`.
- Для курсов, медицинской или социальной тематики, работы по брендбуку и снятия тревоги проверяй `first-aid-courses-tilda`.
- Для e-commerce, фильтров, карточек товаров, корзины и оформления заказа проверяй `flooring-store-redesign`.
- Для юридических услуг, банкротства, большого объема текста и крупного многостраничного проекта проверяй `legal-company-redesign`.
- Для локальной промышленной услуги, прайс-листа и нескольких каналов обращения проверяй `scrap-metal-corporate`.
- Для IT, digital-агентства, нескольких услуг, портфолио и подробных кейсов проверяй `development-studio-redesign`.
