# Система макета

## Сетка

- Фрейм страницы 1920, контент 1200 по центру (x = 360…1560). На мониторе 1280 остаются поля по 40, на 1440 и 1920 всё по центру.
- 12 колонок по 78, гаттер 24 — все доли целые: 1 кол. 78, 2 — 180, 3 — 282, 4 — 384, 6 — 588, 8 — 792, 12 — 1200.
- Типовые раскладки: 3 карточки × 384, 4 × 282, 2 × 588, 1 большая 588 + 2×2 по 282.
- Включи layout grid на фрейме страницы (COLUMNS, CENTER, 12, 78, 24, полупрозрачный акцентный цвет).
- Фоновые подложки блоков — на всю ширину 1920 или «карточкой» 1840 (поля по 40) со скруглением 40.
- Тексты и кнопки всегда внутри 1200. За колонку могут выходить только фото, декор и подложки.
- Constraints у контента — `CENTER` по горизонтали; у фонов и полос — `STRETCH`.
- Для Tilda: фрейм 1200, контент 1160, каждый блок — отдельный фрейм (см. knowledge-base.md).

## Числа

- Все x, y, ширины, высоты, кегли и интерлиньяжи — целые. В конце прогоняй `scripts/audit-integers.js`.
- Отступы кратны 8: 8, 16, 24, 32, 40, 48, 64, 80, 120. Между секциями 120, внутри карточки 24–40.
- Скругления: кнопки и поля 12, карточки 24, крупные подложки 32–40, бейджи — половина высоты.
- Обводки 1 или 2 px. Наклоны декоративных фото — целые градусы от −6° до +6°.

## Типографика

- **Шрифт берётся с цветового референса** (или из брендбука). Unbounded и Manrope не использовать — заказчик их отверг. Если шрифт референса не определяется точно, подбери ближайший доступный в Figma (`listAvailableFontsAsync`) и назови его пользователю.
- Все тексты — через текстовые стили с префиксом проекта (`V3/…` или `<Проект>/…`), капс — свойством `textCase` стиля.
- Шкала (кратно 4, подгоняй начертания под шрифт):

| Стиль | Размер / интерлиньяж | Примечание |
| --- | --- | --- |
| Display/H1 | 64 / 72 | капс, один на страницу |
| Heading/H2 | 44 / 52 | капс или обычный — как в референсе |
| Heading/H3 | 24 / 32 | заголовки карточек и форм |
| Heading/H4 | 20 / 28 | названия пунктов, вопросы FAQ |
| Numbers/Stat | 48 / 56 | цифры-факты |
| Numbers/Price | 24 / 32 | цены |
| Body/Lead | 20 / 32 | лид первого экрана |
| Body/L | 20 / 28 | подзаголовки секций (если нужно 18/28 — допустимо) |
| Body/Base | 16 / 24 | основной текст |
| Body/Small | 12–14 / 20 | подписи |
| Label/Eyebrow | 12–14 / 20 | капс, надзаголовок |
| Label/Button | 16 / 24 | кнопки |
| Display/Wordmark | 160 / 160 | огромный логотип-текст в подвале |

- Мелкий текст — колонкой не шире 800 px.
- Двухцветный заголовок: последняя строка приглушённым или акцентным цветом (приём из референса композиций).

## Цвет

- Палитру снимай с цветового референса в стили `<Проект>/Brand/*`, `Surface/*`, `Text/*`, `Border/*`.
- Минимум: акцент + его hover, светлый фон, бежевая поверхность, белый, тёмная поверхность, основной/вторичный текст, текст на тёмном (основной и приглушённый), границы светлая и тёмная, пастельный оттенок акцента.
- Заливки через `setFillStyleIdAsync`, не hex.

## Компоненты (без автолейаута)

Автолейаут не делать — пользователь расставляет его сам. Компонент — для всего, что повторяется. Доска `Компоненты` рядом со страницей.

Базовый набор:
- `icon/*` 24×24, stroke 2 (Lucide-подобные SVG), никогда не масштабировать — иначе дробная обводка.
- `Button` — Type (Primary / Secondary / Light) × Size (L 56 / M 48); свойства Label (TEXT) и Icon (BOOLEAN). Лейбл с constraint STRETCH, иконка — RIGHT.
- `Logo` (Dark / Light) — заглушка, пока нет SVG заказчика.
- `Badge`, `Input`, `Ornament` (элемент бренда), `Stat`.
- Карточки под задачу: преимущество, товар/услуга (с BOOLEAN «Badge»), удобство-«билет», активность (фото + градиент), шаг, отзыв, `FAQ item` (Closed / Open).
- `PhotoFrame` — фото в светлой рамке с тенью, фото внутри STRETCH; основа асимметричных блоков.
- Декор: `Decor/Waves`, `Decor/Fish` или другой линейный рисунок по теме бренда, обводка 2, цвет акцента.
- `Header` — шапка 1920 как компонент.

Текстовые поля карточек — свойства TEXT, чтобы менять в инстансе. Высоту текстов в компоненте рассчитывай на самый длинный вариант (заголовки в 2 строки — фиксированная высота + вертикальное выравнивание BOTTOM).

## Ритм блоков

Чередуй: обычный → асимметричный → два обычных → асимметричный… Первый экран считается обычным. Асимметричные блоки не должны выбиваться из стиля:
- один и тот же `PhotoFrame`;
- наклоны целыми градусами −6…+6;
- один линейный декор цвета акцента;
- та же палитра, шрифт и скругления.

## Именование

PascalCase латиницей без цифр: `Header`, `Hero`, `HeroStats`, `Ticker`, `WhyUs`, `Houses`, `Amenities`, `Gallery`, `Booking`, `Activities`, `Steps`, `Reviews`, `Faq`, `Contacts`, `Footer`, `ThankYou`. Внутри: `Title`, `Text`, `Photo`, `Button`, `Badge`. Фрейм страницы — `<Проект>Landing1920`.
