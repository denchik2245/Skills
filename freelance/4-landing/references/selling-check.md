# Проверка продаваемости

Делай после сборки и до итога. Правила из базы знаний — лишь часть критериев. Ниже — общепринятые подходы конверсионного дизайна:
- тест 5 секунд;
- модель LIFT (ценность, релевантность, ясность, тревожность, отвлечение, срочность);
- AIDA и PAS;
- принципы влияния Чалдини;
- модель поведения Фогга (мотивация × простота × побуждение);
- закон Хика.

Применяй их здраво, а не механически: цель — чтобы посетитель понял, захотел и сделал целевое действие без лишних вопросов.

## Как проверять

1. **Тест 5 секунд.** Посмотри на скриншот первого экрана (1920×1000, уменьшенный до ~1000 px). Без прокрутки должно быть понятно:
   - что продают;
   - кому;
   - почему стоит выбрать именно это;
   - сколько стоит или «от»;
   - что нажать.
2. **Тест заголовков.** Выпиши H1 и все H2 подряд. Они должны читаться как связная продажа: оффер → выгоды → выбор и цена → доказательства → как купить → снятие сомнений → действие. Если заголовок можно поставить на любой сайт («Наши преимущества», «О нас») — перепиши.
3. **Проход по блокам** глазами посетителя, который сомневается. На каждом блоке спроси:
   - зачем мне это знать;
   - верю ли я этому;
   - что мне делать дальше.
4. **Оценка** по таблице ниже: 0 — нет, 1 — частично, 2 — есть. Подсчитай процент.
   - **Ниже 80%** — исправь в макете всё, что исправляется без данных заказчика, и пересчитай.
   - **Остальное** — в список вопросов заказчику.

## Критерии

| Группа | Критерий | Что считать «есть» |
| --- | --- | --- |
| Оффер | Понятно за 5 секунд | H1 + лид отвечают «что, кому, какая польза» без жаргона |
| | Отличие от конкурентов (УТП) | Есть причина выбрать именно этот вариант, а не соседний: место, формат, сервис, цена, гарантия |
| | Выгоды, а не характеристики | Каждая характеристика переведена в результат для клиента («баня на территории» → «после рыбалки — сразу в парную») |
| | Конкретика | Цифры, сроки, состав, цены вместо «качественно», «комфортно», «индивидуальный подход» |
| Релевантность | Совпадение с запросом | В H1/H2 — слова, которыми ищут (вид услуги, гео); сегменты аудитории названы |
| Ясность | Иерархия | На каждом экране один главный заголовок, одно главное действие; текст сканируется (абзацы ≤ 4 строк, колонка ≤ 800) |
| | Выбор упрощён | Варианты сравнимы по одним параметрам; один выделен как рекомендуемый (закон Хика) |
| Тревожность | Цена прозрачна | Цена или «от» видна; ясно, что входит и что доплачивается |
| | Риски сняты | Условия предоплаты, отмены и возврата, гарантии, что будет после заявки |
| | Подлинность | Реальные фото продукта, людей, процесса; адрес, контакты, реквизиты или юрлицо в подвале |
| Доверие | Социальное доказательство | Отзывы с деталями (имя, дата, что купили), рейтинг внешней площадки со ссылкой, число клиентов или лет |
| | Авторитет | Эксперты, сертификаты, партнёры, публикации — если есть |
| Мотивация | Эмоция и результат | Фото и тексты показывают результат («вечер у костра»), а не только объект |
| | Честная срочность | Сезон, свободные даты, ограниченное число мест — только если правда; без фальшивых таймеров |
| Действие | CTA | Глагол + выгода, контрастный цвет; повторяется после ключевых блоков (каждые 1–2 экрана) |
| | Микротекст у CTA | Под кнопкой снят страх: «без предоплаты», «перезвоним за 15 минут», «ответ в мессенджер» |
| | Без отвлечений | Рядом нет равнозначных кнопок; второстепенное — ссылкой; внешние ссылки не уводят из воронки |
| | Форма | Минимум полей; сказано, что будет после; есть альтернативный канал (телефон, мессенджер) |
| Путь | Порядок AIDA | Доказательства и цены идут до финальной формы; FAQ закрывает возражения перед последним CTA |
| | Возврат к действию | В шапке есть CTA или телефон; после «Спасибо» есть следующий шаг (бонус, полезная ссылка) |

## Что делать с результатом

- **Исправлять сразу** (не нужны данные заказчика):
  - формулировки заголовков и CTA;
  - лишние или двойные кнопки;
  - отсутствующий микротекст у CTA;
  - пропущенный повтор CTA;
  - порядок блоков;
  - выделение рекомендуемого варианта;
  - читаемость и иерархию.
- **В заглушки и вопросы заказчику:**
  - УТП, если его нет во входных данных;
  - условия предоплаты и отмены;
  - реальные отзывы и рейтинг;
  - гарантии, сертификаты;
  - реальные фото.
- **В итоговом сообщении** покажи:
  - процент до и после правок;
  - 3–5 главных правок;
  - что мешает дотянуть до 100% и что для этого нужно от заказчика.
