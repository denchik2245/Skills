# Что дать на вход

Чем больше фактов и материалов заказчика, тем меньше заглушек и тем сильнее продающий текст. Минимум для старта — пункты 1–4. Остальное можно добрать вопросами.

## Обязательно

1. **Куда рисовать** — ссылка на файл Figma и страницу/узел (`node-id`). Можно ли создавать новые страницы и текстовые/цветовые стили.
2. **Материал заказчика** — макет, скриншоты, текущий сайт или бриф. Пометка: что заказчику нравится и что обязательно сохранить (структура, блоки, тексты, цены).
3. **Бизнес-факты** — что продаём, кому, главное целевое действие (заявка, звонок, бронь, покупка), цены и что в них входит, география, контакты, часы работы.
4. **Референсы с ролями** — для каждого скрина: что именно берём.
   - «цвета» — палитра, а также **шрифт** и форма кнопок этого референса;
   - «композиции» — какие именно блоки понравились (лучше скрин блока, а не всей страницы);
   - «настроение / фото» — стиль съёмки.

## Сильно улучшает результат

5. **Платформа** — Tilda (фрейм 1200, контент 1160, свои правила слоёв) или кастомная вёрстка (по умолчанию фрейм 1920, контент 1200).
6. **Логотип** в SVG и брендбук, если есть.
7. **Реальные фото** продукта/объекта/команды (или разрешение брать из других страниц файла). Можно ли генерировать недостающие через Figma AI — это тратит кредиты.
8. **Доказательства** — отзывы с именами и датами, рейтинг и число оценок на картах/площадках, годы работы, число клиентов, гарантии, сертификаты, партнёры. Без них в макете будут помеченные заглушки.
9. **Ответы на частые вопросы** клиентов — для FAQ.
10. **Бонус для страницы «Спасибо»** — что можно пообещать после заявки.

## Можно уточнить, иначе — значения по умолчанию

| Параметр | По умолчанию |
| --- | --- |
| Ширина фрейма / контента | 1920 / 1200 (12 колонок 78 + 24) |
| Автолейаут | не делаю, только компоненты для повторяющихся элементов |
| Состав | главная страница + «Спасибо» + доска компонентов |
| Мобильная версия | не делаю, пока не попросят |
| Ритм блоков | обычный → асимметричный → два обычных → асимметричный… |
| Язык | русский |
| Шрифт | с цветового референса; не Unbounded/Manrope |

## Шаблон брифа

```
Figma: <ссылка с node-id>
Платформа: Tilda / вёрстка
Материал заказчика: <скрины/ссылка>; сохранить: <что>
Бизнес: <что продаём, кому>; целевое действие: <...>
Цены: <...>; входит в стоимость: <...>
Контакты: <телефон, мессенджеры, почта, адрес, часы>
Референс цветов (+шрифт): <скрин>
Референс композиций: <скрины блоков>; нравится: <что именно>
Фото/логотип: <ссылки или «бери со страниц ...»>; генерация AI: да/нет
Доказательства: <отзывы, рейтинг, цифры>
FAQ: <вопросы и ответы>
Бонус «Спасибо»: <...>
Особые пожелания: <...>
```
