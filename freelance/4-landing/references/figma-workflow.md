# Работа с Figma MCP

## Подготовка

1. `create_session` с fileKey из ссылки; sessionId передавай во все вызовы.
2. Прочитай `skill://figma/figma-use/SKILL.md` и `skill://figma/figma-generate-design/SKILL.md` (обязательны перед `use_figma`). Их правило «используй auto-layout» здесь **не действует**: пользователь просит без автолейаута.
3. Разведка одним скриптом: страницы, существующие стили (`getLocalTextStylesAsync`, `getLocalPaintStylesAsync`), доступные шрифты (`listAvailableFontsAsync` — сверяй точные названия начертаний: `SemiBold` vs `Semi Bold`).
4. По каждой странице параллельно — список картинок (`findAll` по `fills[].type==='IMAGE'`, уникальные `imageHash`). Собери контактный лист: временный фрейм с прямоугольниками по хешам и номерами → `get_screenshot` → удалить. Так понятно, какие фото есть, без загрузки.

## Порядок сборки

1. Стили цвета и текста с префиксом проекта.
2. Доска `Компоненты`: иконки (SVG через `createNodeFromSvg`, перенос детей в `createComponent`), кнопки, логотип, бейджи, поле ввода, карточки, `PhotoFrame`, декор, Header.
3. Фрейм страницы 1920 с layout grid. Секции — отдельными фреймами внутри (`clipsContent=false` у секций с наклонёнными фото).
4. Секции партиями по 2–3 в одном вызове; каждый вызов возвращает id и нижнюю границу.
5. Скриншот каждой секции через `get_screenshot` по id секции (exportAsync теряет картинки — не используй его для проверки).
6. Страница «Спасибо».
7. `scripts/fix-hanging.js` (страховка от висячих предлогов в текстах, набранных мимо `T()`/`prop()`), `scripts/audit-integers.js`, финальный скриншот всей страницы.
8. Проверка продаваемости по `selling-check.md` по финальному скриншоту; правки — точечно, затем повторный скриншот изменённых блоков.

`scripts/prelude.js` — помощники R/F/T/I, `nb`, `prop`, `textProps`, `swapIcon`, `shiftBelow`. `T()`, `prop()` и `textProps()` сами ставят неразрывные пробелы через `nb()`; `T(..., {raw: true})` — если текст нужно оставить как есть (артикул, код). При ручной правке `characters` тоже оборачивай строку в `nb()`. Вставляй его в начало каждого скрипта, подставив PAGE_ID и PREFIX.

## Грабли, на которые уже наступали

- Ошибка в середине скрипта откатывает весь вызов — проверь холст коротким чтением и запусти исправленный скрипт целиком.
- Не изобретай переменные в выражениях (`const a = B = …` → ReferenceError).
- Детей инстанса нельзя двигать и ресайзить. Позицию и размер текстов задавай в главном компоненте, в инстансе меняй только свойства, заливки и видимость.
- Кнопка без иконки: лейбл останется смещённым — оставляй иконку видимой или делай отдельный вариант.
- Тексты под самый длинный вариант: замеряй в компоненте; для заголовков в 2 строки — фиксированная высота + `textAlignVertical='BOTTOM'`.
- После смены шрифта ширины меняются: перемерь однострочные тексты (`textAutoResize='WIDTH_AND_HEIGHT'` → `Math.ceil(width)` → `HEIGHT`) в меню, бегущей строке, подписях, подвале; потом перецентрируй центрированные заголовки: `x = (parent.width - width) / 2`.
- Центрированный текст при авто-ширине смещает x — после замера ставь x заново.
- `combineAsVariants` складывает варианты в кучу — расставь детей набора и задай размер набора вручную.
- Свойства набора вариантов добавляй на COMPONENT_SET, ссылки (`componentPropertyReferences`) — в каждом варианте.
- Вырез у «билета»: `figma.subtract([rect, circleL, circleR], component)`, затем заливка стилем.
- Повёрнутые узлы получают дробные x/y — это нормально, аудит их пропускает.
- Сгенерированные через `generate_image` картинки появляются на первой странице; забери `imageHash` и удали узел.
- Скрытый в инстансе слой (линия, иконка) всё равно занимает место, отведённое ему в компоненте: отступы карточки становятся неравными. Если элемент не нужен — убери его и место под него из главного компонента или сделай вариант без него; после размещения сверь верхний и нижний внутренние отступы.
- Если высота секции изменилась — сразу `shiftBelow` для всего ниже, включая фрейм «Спасибо».

## Картинки

Приоритет: фото заказчика → фото с других страниц файла (по хешу) → `generate_image` (тратит кредиты Figma AI, спроси, если не разрешено заранее, и сообщи после). Не загружай скриншот всего макета заказчика как картинку в макет.
