# Figma → Zero Block

Как `to-zero.mjs` переводит слои и что после него проверить руками. Формат JSON и допустимые ключи — в `zero_block_instructions` Tilda MCP; если они расходятся с этим файлом, верен Tilda MCP.

## Сетка и координаты

- Сетка Zero Block — `--grid` px по центру окна. Слой с `x` в Figma получает `left = x − (ширина фрейма − grid) / 2`: во фрейме 1920 с контентом 1200 слой на `x = 360` встаёт на `left = 0`.
- Слой на всю ширину фрейма (`x = 0`, ширина = ширине фрейма, без поворота) — `container: window`, ширина 100 %: фон или полоса тянется на любое окно.
- Всё, что левее или правее сетки, остаётся там же (отрицательный `left` или больше `grid`) — так и выглядят фото навылет. Тексты и кнопки должны быть внутри сетки.
- Повёрнутый слой: Tilda вращает элемент вокруг центра, Figma хранит угол угла рамки. Выгрузка уже пересчитала невращённую рамку вокруг того же центра; `rotate` = −угол Figma, потому что Figma считает против часовой стрелки, а CSS по часовой.
- Координаты округляются до целых. Дробные значения в Figma — повод поправить макет (`audit-layout.js` в 0-figma).

## Слои

| Figma | Zero Block | Что проверить |
| --- | --- | --- |
| Фрейм секции | артборд: `ab_height`, `ab_bgcolor`/`ab_bgimg`, `ab_title` = имя фрейма | фон картинкой на мобильном кадрируется иначе |
| Фрейм с автолейаутом | физическая группа `flex: auto`: направление, отступы, промежутки, выравнивание; размеры детей — fixed/hug/fill | порядок в потоке идёт по убыванию `zindex` — скрипт уже развернул его; `SPACE_BETWEEN` по поперечной оси не переносится |
| Фрейм без автолейаута с заливкой, обводкой, тенью или обрезкой | физическая группа без flex | дети считаются от сетки артборда, а не от угла группы |
| Фрейм или группа без оформления | логическая группа (только выделение в редакторе) | — |
| Фрейм без автолейаута внутри автолейаута | физическая группа без flex (`FREE_FRAME_IN_FLEX`) | дети потеряют положение при движении потока — добавь автолейаут в Figma или перестрой группу |
| Текст | `text`: `tag` h1–h3 по имени стиля (`Display`, `H1`, `H2`, `H3`), кегль, начертание, межстрочный как коэффициент, трекинг в px, регистр, цвет | ровно один `h1` на странице; перенос строк в браузере может отличаться на слово |
| Диапазоны другого цвета, начертания, кегля | `<span style>` внутри текста | другое семейство или регистр в диапазоне не переносится (`MIXED_*`) |
| Ссылка в тексте | `<a href>` | если у всего текста есть ссылка элемента — `<a>` внутри нельзя |
| Неразрывный пробел | `#nbsp;`, как в `zero_block_instructions` | в `get_record_html` должен стать `&nbsp;`; если `#nbsp;` виден буквально — пересобери с `--nbsp '&nbsp;'` |
| Группа или инстанс с именем `Button…`, в котором один текст | `button`: подпись, заливка подложки, радиус, обводка, размеры | ссылку (`BUTTON_NO_LINK`) и иконку (`BUTTON_ICON`) ставишь сам: `btn_icon` из встроенных стрелок Tilda или отдельный `vector` |
| Прямоугольник, эллипс-круг | `shape` rectangle/circle | эллипс не круг (`ELLIPSE_NOT_CIRCLE`) станет скруглённым прямоугольником — экспортируй SVG |
| Линия | `shape` высотой в толщину обводки | пунктирные линии — SVG |
| Слой с заливкой-картинкой | `image`: `cover` для FILL, `contain` для FIT, файл из `assets.json` | CROP и TILE не переносятся (`IMAGE_SCALE_MODE`): кадрируй через `imageposition: custom` или экспортируй слой |
| Иконка: вектор, булева операция, группа из векторов до 160 px или с именем icon/svg/logo | `vector` с SVG; иконки на 960 не уменьшаются | SVG больше 15 KB и с растром внутри — картинкой |
| Группа с маской | картинка-экспорт всей группы (`MASK_EXPORTED_AS_IMAGE`) | текст внутри маски станет частью картинки — вынеси его из маски в Figma |
| Скрытый слой | пропускается (`HIDDEN_SKIPPED`) | если он нужен для состояния, сделай его в Tilda |

## Цвет и эффекты

- Цвета переменных Figma выгружаются разрешёнными для активного режима и с именем переменной. С `--styles` цвет, совпавший со стилем проекта, пишется как `var(--uc-color-color-<id>,#hex)` — см. [project-styles.md](project-styles.md).
- Линейный градиент переводится в `linear-gradient` с пересчётом угла и стопов; радиальный и угловой — приближённо (`GRADIENT_APPROX`), сверь со скриншотом.
- Тени (наружные и внутренние) — `shadows`; размытие слоя и фона — `effects` (радиус Figma ÷ 2). Только один фильтр на элемент.
- Режимы наложения, несколько заливок на одном слое, обводка снаружи или по центру, тени текста не переносятся точно — они в предупреждениях. Обводку Tilda рисует внутри элемента.
- Цвета и эффекты одинаковы на всех брейкпоинтах. Если в мобильном фрейме другой цвет — это отдельный слой (скрыть/показать по брейкпоинтам).

## Брейкпоинты

| Брейкпоинт | Откуда значения |
| --- | --- |
| 1200 (без суффикса) | десктопный фрейм |
| 960 | десктоп × 0,8; кегли не меньше 14 px (или исходного, если он меньше); иконки в исходном размере |
| 640, 480, 360 | мобильный фрейм по центру сетки: `left` + (брейкпоинт − 360) / 2 |
| уже мобильной сетки (320) | мобильный фрейм × брейкпоинт / 360 |

- Слои десктопа и мобильного фрейма сопоставляются по пути имён: `Content/Title`, повторы — `Card#2`. Одинаковые имена в обоих фреймах обязательны, иначе слой станет «только десктоп» и «только мобильный».
- Слой только на десктопе — `hidden-res-640: y`; только в мобильном фрейме — `hidden: y`, `hidden-res-640: n`. Это допустимо для разной композиции, но плодить дубли ради сдвига нельзя.
- Текст на всех брейкпоинтах один (`MOBILE_TEXT_DIFFERS`). Другой текст на мобильном — отдельный слой с другим именем.
- Высота артборда: десктоп, десктоп × 0,8, высота мобильного фрейма.
- Свои брейкпоинты — `--screens` и `--mobile-from`; самый широкий должен совпадать с `--grid`.

## Что делать с предупреждениями

| Код | Действие |
| --- | --- |
| `NO_MOBILE_FRAME` | не сдавать: мобильный фрейм в Figma (0-figma) или ручные `-res-` ключи по правилам адаптива |
| `missingAssets` в отчёте | загрузить файлы, дописать `assets.json`, пересобрать |
| `DESKTOP_ONLY_LAYER`, `MOBILE_ONLY_LAYER` | убедиться, что это намеренно, а не опечатка в имени |
| `TEXT_LINK_DROPPED`, `BUTTON_NO_LINK` | проставить ссылки по плану |
| `ABSOLUTE_IN_FLEX`, `FREE_FRAME_IN_FLEX`, `FULL_WIDTH_GROUP` | проверить положение на всех брейкпоинтах в браузере |
| `GRADIENT_APPROX`, `*_BLEND_MODE`, `MULTIPLE_FILLS`, `STROKE_ALIGN`, `TEXT_SHADOW` | сверить со скриншотом; если заметно — экспортировать слой картинкой или упростить в Figma и сказать пользователю |
| `MISSING_FONT` | шрифт не установлен в Figma — выясни настоящий шрифт до переноса |
