# Проверка переноса

Проверяй на странице Tilda, где работают её скрипты, а не по JSON. Результаты записывай в `checks.md` рабочей папки: строка — проверка, результат, что исправлено.

## Где смотреть

1. Опубликованная страница, если пользователь разрешил публикацию.
2. Иначе — `page_preview`: сохрани HTML в файл, добавь в `<head>` `<base href="<адрес сайта проекта>/">`, открой через локальный сервер (`python3 -m http.server` в папке файла) во встроенном браузере.
3. Отдельный блок — `get_record_html` (HTML, CSS и JS с несохранёнными изменениями), удобно после точечной правки.

Перед сравнением дождись `document.fonts.ready` и загрузки картинок, прокрути страницу до конца и обратно.

## Что проверить

| Проверка | Как | Готово, когда |
| --- | --- | --- |
| Структура | `get_page_records` | все блоки плана на месте и по порядку, якоря заданы |
| Десктоп | ширина окна 1440 (сетка 1200 по центру) и 1920; скриншот каждого блока рядом с эталоном `get_screenshot` | положение и размеры заголовков, текстов, кнопок, картинок совпадают в пределах 1–2 px |
| 960 | ширина 1000 | ничего не вылезает за край, тексты не налезают |
| Мобильные | ширины 640, 480, 375, 360; эталон — скриншот мобильного фрейма | совпадает с мобильным фреймом; нет горизонтальной прокрутки |
| Тексты | скрипт ниже на каждой ширине | ни один текст не перекрывает другой текст или кнопку; переносы не ломают кнопки и цены |
| Шрифты | `getComputedStyle(el).fontFamily` у заголовка и текста, `document.fonts.check(...)` | загружен тот же шрифт, что в макете, или согласованная замена |
| Картинки | все `img` с `naturalWidth > 0`, адреса только `static.tildacdn.com` / CDN Tilda | нет ссылок на Figma, localhost и временные URL |
| Ссылки | клик по каждой кнопке и пункту меню | ведут на якорь, страницу или попап из плана; якорь не прячется под фиксированной шапкой |
| Формы | валидация и сообщение об успехе; тестовая отправка — только с разрешения | отправляются в выбранного получателя, после отправки — «Спасибо» |
| Консоль | `read_console_messages` | нет ошибок, которых нет на пустой странице Tilda |

## Скрипт: наложения и прокрутка

Выполни в странице через `javascript_tool` на каждой ширине:

```js
(() => {
  const items = [...document.querySelectorAll('.t396__elem')]
    .filter(el => el.offsetParent && el.querySelector('.tn-atom'))
    .filter(el => ['text', 'button'].includes(el.dataset.elemType))
    .map(el => ({ el, r: el.getBoundingClientRect(), id: el.dataset.elemId }));
  const hits = [];
  for (let i = 0; i < items.length; i++) for (let j = i + 1; j < items.length; j++) {
    const a = items[i].r, b = items[j].r;
    const x = Math.min(a.right, b.right) - Math.max(a.left, b.left);
    const y = Math.min(a.bottom, b.bottom) - Math.max(a.top, b.top);
    if (x > 2 && y > 2 && !items[i].el.contains(items[j].el) && !items[j].el.contains(items[i].el)) hits.push([items[i].id, items[j].id, Math.round(x), Math.round(y)]);
  }
  return { width: innerWidth, hScroll: document.documentElement.scrollWidth > innerWidth, overlaps: hits };
})();
```

Селекторы рассчитаны на текущую разметку Zero Block (`.t396__elem` с `data-elem-id` и `data-elem-type`); если список пуст, сверь классы по `get_record_html`.

Наложение, которое есть в макете намеренно (надпись на фото, стикер на заголовке), отметь в `checks.md` как допустимое. Остальные исправь: увеличь отступ ниже текста, уменьши кегль на брейкпоинте или переведи столбец текстов в группу с автолейаутом.

## Типичные расхождения и исправления

- **Текст стал на строку выше**, чем в Figma: другой рендер шрифта или ширина без запаса. Дай тексту на 2–4 px больше ширины или сдвинь элементы ниже; в группе с автолейаутом поток сдвинет их сам.
- **Шрифт не тот**: не подключён в проекте или имя семейства отличается — проверь `fontfamily` и настройки шрифтов проекта.
- **Блок обрезан снизу**: `ab_height` меньше фактического содержимого на брейкпоинте — подними высоту на этом брейкпоинте.
- **На 960 элемент уходит за край**: элемент навылет из десктопа — задай ему `left-res-960` или скрой на этом брейкпоинте.
- **Белые полосы по бокам на широком экране**: фон задан элементу внутри сетки, а не артборду или элементу с `container: window`.

Исправления после загрузки вноси через `update_zero_block_partial` и перепроверяй только затронутые блоки и ширины. В итоговом отчёте перечисли ширины, на которых смотрел, и всё, что проверить не удалось.
