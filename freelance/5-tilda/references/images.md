# Картинки: быстрая загрузка

Каждая фотография весит столько, сколько нужно для её размера на экране, и загружена в Tilda как WebP. Tilda помогает сама: при включённой оптимизации её lazyload подгружает картинку в размере элемента (`-/resize/<ширина>x/`) и в WebP (`-/format/webp`) через `optim.tildacdn.com`. Но первый экран грузится без lazyload, напрямую исходным файлом, поэтому исходники тоже должны быть лёгкими.

## Бюджет

| Что | Ширина файла | Вес |
| --- | --- | --- |
| Фото в блоке | наибольший размер показа × 2 (с учётом кадрирования cover), не больше исходника и 2560 px | до 200–250 KB, обычно около 100 KB |
| Фон или фото первого экрана | так же | до 300 KB |
| Иконки, логотипы | SVG (`vector` или `image`) | до 15 KB |
| PNG с прозрачностью | WebP с альфа-каналом | как фото |

## Порядок

1. **Размеры показа.** Собери блоки конвертером один раз без `assets.json`. В отчёте в `images` для каждой картинки есть `key`, узел Figma и наибольший размер показа на всех брейкпоинтах (`maxW`, `maxH`).
2. **Исходники.** Для каждой картинки вызови `download_assets` по `nodeId`: для заливки бери `rawImages`, для маскированной группы — `export`. Ссылки временные, поэтому сразу скачай файлы в `raw/<key>.<format>` (`curl -sL -o …`), двоеточие в ID замени на «-».
3. **Оптимизация.** Запусти `optimize_images.py` (нужен Pillow):

   ```bash
   python3 <папка скилла>/scripts/optimize_images.py --reports 01-hero.zero.report.json,02-about.zero.report.json \
     --src raw --out web --prefix <проект>
   ```

   Скрипт уменьшает фото до нужного размера, сохраняет WebP с качеством 80 и снижает его до 60, пока файл не войдёт в бюджет. Имена файлов понятные (`plume-main-hall.webp`). В `web/manifest.json` записаны размеры и вес до и после. Строки с `note` разбери: исходник слишком мал или не уложился в бюджет.
4. **Загрузка в Tilda.** `upload_image` принимает файл только по публичной ссылке или в base64. Не перепечатывай байты файла в вызов. Передай файлы через Figma:
   - через `use_figma` создай временную страницу `_tilda-upload` с прямоугольниками по числу файлов (имя = имя файла) и верни их ID;
   - `upload_assets` с `count`, `nodeIds` этих прямоугольников и `currentPageId` временной страницы;
   - на каждую полученную ссылку отправь файл: `curl -s -X POST -H 'Content-Type: image/webp' --data-binary @web/<файл> '<ссылка>'`;
   - `download_assets` по каждому прямоугольнику: `rawImages[0].url` — это тот же WebP по временной публичной ссылке;
   - `upload_image` с `image_url`, до 8 штук за вызов, затем `assets.json`: `{ "<key>": { "url", "w", "h" } }`, где `w`, `h` взяты из manifest;
   - удали временную страницу. Это твои временные узлы, другие страницы файла не трогай.

   Если передача через Figma не сработала, загрузи исходники из `rawImages` напрямую. Lazy-картинки Tilda всё равно ужмёт при показе, но для первого экрана скажи пользователю, что файл тяжёлый, и назови вес.
5. **Сборка.** Пересобери блоки с `assets.json`. Блок первого экрана собирай с `--eager`: его картинки получат `lazyoff: y` и загрузятся сразу, без мигания.
6. **Настройки проекта.** В `get_project_settings` `imgoptimoff` и `lazyoff` не должны быть `on` (оптимизация и lazyload включены). `fontsswap: on` показывает текст системным шрифтом, пока грузится веб-шрифт; включай его с согласия пользователя, если в проекте есть другие страницы.
7. **Preload главной картинки.** В head-код страницы (`get_head_code`, затем `update_page_head_code` с сохранением того, что там уже есть):

   ```html
   <link rel="preload" as="image" type="image/webp" fetchpriority="high" media="(min-width: 960px)" href="<CDN десктопного фото>">
   ```

   Если на мобильном другое фото — второй `link` с `media="(max-width: 959px)"`. Если фото одно — `media` не нужен.

## Проверка

- На опубликованной странице или в превью: `performance.getEntriesByType('resource')`. Картинки ниже первого экрана идут с `optim.tildacdn.com` или `static.tildacdn.com` с `-/resize/`, первый экран — исходный WebP из бюджета.
- Сумма `transferSize` картинок первого экрана — в отчёт.
- Нет картинок с Figma, localhost и временных ссылок. У всех фото есть `alt` (см. [seo.md](seo.md)).
- Встроенный браузер в скрытой панели не прокручивает lazyload. Если `innerWidth` равен 0, попроси открыть панель или проверь в видимой вкладке.
